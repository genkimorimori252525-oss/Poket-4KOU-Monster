# Phase 2（反動と間）: 間を選ばせる Verification Report

**Phase Goal:** AI が「撃てるが撃たん」を選び、その間に回避できる
**Status:** passed
**Requirements:** MA-01〜05, STATE-02, VER-01, VER-02, VER-03

## 何が無かったか

`pickMove` は撃てる技から**必ず1つ返す**作りやった。
だから「相手の攻撃のあとの隙を狙う」という読み合いが、そもそも成立しとらん。

## 設計の判断

**「間」を別枠で先に判定せず、同じ softmax に候補として混ぜた。** 理由が3つある:

- **賢さ（温度 T）が自然に効く。** 馬鹿はブレて間を取り損ねるし、取りすぎもする
- **乱数の呼び出しが1回のまま**やけん決定論に触らん（掟1）
- 「なぜ間を選んだか」が他の技と**同じ形でログに並ぶ**（掟9）

重みは `HOLD_W` に集めた。実戦で面白くなかったらここだけ触ればよい。

```
base      -34   土台。理由が無ければ選ばれん高さから始める
foeCharge  42   相手が溜めとる → 大技が来る。避けに回る値打ちがある
foeRecoil -30   相手が撃てん → 好機。ここは間やのうて攻める場面
lowHP      30   一発で落ちる場面で突っ込まん
costly     26   落としたら経済が傾く
cautW/aggrW/selfW   性格の効き
```

**`foeRecoil` を負にしたのが肝。** 計画の下書きでは「相手のCDが明ける＝間を取る理由」と
書いとったが、**逆やった** —— 撃たれん相手に様子見しても仕方ない。
にーくらの言う「攻撃したあとの隙を狙う」の**狙う側**やけん、ここは攻める場面。

## 成功基準ごとの結果

### 1. 撃てるのに撃たん場面が実戦で起きる — ✓ 通過

5戦（種を変えて）回した実測:

```
間を選んだ割合  13.3% / 15.4% / 4.5% / 4.2% / 19.2%
種によって取る個体が変わる（19〜209フレームの幅）
```

### 2. 理由がログに出る — ✓ 通過（MA-02）

条件を作って、点が動くことを確かめた:

```
素             -22
相手が溜め中    18   （+40）
相手が反動中   -49   （−27）← 好機と判断して攻めに回る
こっちが瀕死     5   （+27）
```

内訳は他の技と同じ形でログに並ぶ（`撃てるなら撃つ / 落としたら経済が傾く / 好戦`）。

### 3. 賢さと性格が効く — ✓ 通過（MA-03）

```
馬鹿で好戦 -26  <  並 6  <  賢くて慎重 40
```

**単調に効いとる。** 掟どおり賢さは有利にも不利にも働く ——
賢いほど「今は待つべき」が分かるが、賢すぎると待ちすぎる側にも寄る。

### 4. 極端に寄っとらん — ✓ 通過（MA-04・**この検証の本題**）

「間が実装できた」だけなら、常に間を取る実装でも通ってしまう。
それは読み合いやのうて**ただの棒立ち**や。

```
間を選んだ割合  4.2% 〜 19.2%（5戦とも80%未満・かつ0.5%超）
間を取る個体    5体 / 全6体
```

**全員が取るわけでも、誰も取らんわけでもない。** 性格の差が実戦で出とる。

### 5. 間の最中に回避が起きる — ✓ 通過（MA-05）

```
回避判断 全46回のうち、間の最中が 4回
```

溜め中は「溜めを捨てる」の減点が入るけん避けにくい。
**間は溜めを持っとらんけん、その減点が無い** —— それが間を取る値打ちの一部や。

### 6. 決定論 — ✓ 通過（掟1）

```
determinismTest()        ok
同じ種で2回走らせて一致  true
```

間の抽選は既存の `battleRng` の**同じ1回**に乗っとる。乱数を増やしとらん。
