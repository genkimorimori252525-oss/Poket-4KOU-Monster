# Phase 3: ファイル保存と戦闘への配線 Verification Report

**Phase Goal:** 作った四皇モン・技・音がファイルとして残り、その個体が戦闘に出てくる
**Status:** human_needed —— 機械で確かめられる範囲はすべて通過。**画面で見た感じだけは人の目が要る**
**検証者:** オーケストレーター（Claude）が直接実行。サブエージェントは使っていない

## 成功基準ごとの結果

### 1. 保存が `data/` のファイルになり、容量の警告なく何体でも保存できる — ✓ 通過

```
npm run verify:store  exit=0
  サーバー経由   mode=files  5体読み込み  写真も鳴き声もURL（localStorage を食わん）
  保存テスト     既存の保存経路で atk を変更 → data/monsters/Mantis.json が実際に変わった
```

技の棚・音設定・草むら・自動保存も同じくファイルへ。25ファイルが git 追跡下。

**設計データが読める大きさになった**（写真と鳴き声を外へ出したため）:

| 個体 | 移行前 | 移行後 |
|---|---:|---:|
| バゼルギウス | 66 KB | **4.7 KB** |
| パルキア | 32 KB | 5.4 KB |
| ロッツォ | 29 KB | 2.5 KB |
| ちんすけ | 25 KB | 2.4 KB |
| かまきり | 17 KB | 2.2 KB |

これで `git diff` が人間に読める。攻撃力を60→55にしたときの差分は**1行**:

```
-    "atk": 60,
+    "atk": 55,
```

にーくらの「全キャラの攻撃力を見直したい」が成立する形になった。

### 2. 既存データが1件も欠けずに移行される（SAVE-07） — ✓ 通過

```
npm run verify:migration  exit=0
  個体 5体すべて、ファイルから戻したら元と1バイトも違わんかった。
  メディア 121 KB を含めて往復一致。
```

「移行できたはず」やのうて「**ファイルから組み立て直したら元と同じやった**」で示している。

**この検査は実際に仕事をした。** 同じ欠陥を2回、別々の経路で捕まえている:

1. 移行スクリプトが MIME を `;` で切って先頭だけ取り、`audio/webm;codecs=opus` の
   **`;codecs=opus` 12文字を捨てとった**（4体の鳴き声）
2. 直したあと、ブラウザを往復する経路でも同じ12文字が落ちた（橋渡しが URL 化のときに
   mime を捨てとった）。URL のクエリに積んで往復させる形にして解決

どちらも「移行できたっぽい」で進めとったら、にーくらの鳴き声から静かにコーデック指定が消えとった。

### 3. サーバー不在でも `file://` で今までどおり保存できる — ✓ 通過

```
file:// 直開き  mode=localStorage
  「file:// で開いとるけん、保存先は今までどおりブラウザの中（localStorage）。」
```

掟「`dist/` は単体で開ける」を壊していない。保存先がどちらかは `window.STORE_NOTE` に出る
（黙って別の箱に入れない）。

### 4. 保存を壊しても `git checkout` で戻せる — ✓ 通過

`data/` 25ファイルが git 追跡下。実際に検証中、テストが書き換えた `data/` を
`git checkout -- data` で戻す運用を繰り返している。

制作ツールで作った個体は、影も鳴き声も自作技も戦闘側から一度も読まれとらんかった。それが繋がった。

**決定論が壊れとらんことも同時に確認**（保存個体を出した状態で `determinismTest()` が ok）。

## 途中で見つけて直した、俺自身のバグ

**鳴き声の URL を `SND.addCustom()` にそのまま渡して `atob` が落ちた。**
`dist/` の `SoundBank.decodeOne()` は data URI しか扱えん（URL 対応は `dist-dev/` の
ビルド時パッチにしか無い）。**`src/sfx_bank.js` は手で編集せん掟**やけん、
橋渡し側で URL を取ってきて data URI に変えてから渡す形にした。

検証が無ければ「鳴き声が鳴らん」だけが残って、原因が分からんかった。

## 掟をどう守ったか

- **`src/sfx_bank.js`** … HEAD とハッシュ一致。1バイトも触っとらん
- **掟1（決定論）** … 保存個体を出した状態で `determinismTest()` が ok
- **掟8（音の決定権）** … 自作技の音は `AUDIO_CFG` 側が既にあればそっちを優先。
  個体に抱えさせて上書きしない
- **掟「dist/ は単体で開ける」** … `file://` では今までどおり localStorage
- **影の既定値** … `mon.shadow` を持たん個体の見た目は1ピクセルも変わらんよう、
  既定値を現行の値そのものにしとる
