# Roadmap: ポケット四皇モンスター（コスト経済）

## Overview

このマイルストーンが入れるのは、**コストを「編成の枠」から「陣営の体力」に変える**という一点。

今のコードには**枠としてのコストは在る**（`costOf` の仮式、個体ごとの COST 表示）。
無いのは**経済**のほう —— 所持コスト・その増減・敗北条件・バー。数えたら全部 0 箇所やった。
計画が「本作の中核仕様」と呼んどる部分が丸ごと空いとる。

順番には理由がある。計画18.5 が警告しとる ——「コストは**損失額と獲得額の両方**を
決めるようになった。不当に安い個体は三重取りして確実に壊れる」。だから**式を差し替えられる
形にしてから**（Phase 1）、経済を載せる（Phase 2）。見える化は最後（Phase 3）—— 数字が
動いとらんうちにバーを作っても、何も映らんけん。

`src/sfx_bank.js` は全フェーズを通して不可触。`dist/` の「外部ファイル参照ゼロ・単体で開ける」も
最後まで壊さない。ゲーム本編の他フェーズ（16 死亡・17 特性・22 育成）には手を出さん。

## Phase Details

### Phase 1: コストを独立させる

**Goal**: コストの式が1箇所にまとまり、書き換えても呼び出し側を触らんで済む
**Mode:** mvp
**Depends on**: Nothing (first phase)
**Requirements**: COST-01, COST-02, COST-03, VER-02, VER-03

今 `costOf` は `src/moves.js` の中に埋まっとる。呼び出しは `battle.tpl.html`・`roster.js`・
`creator.tpl.html` に散っとる。これを `src/cost.js` へ剥がす。

**このフェーズで挙動が変わったら失敗。** 全個体のコストが差し替えの前後で
同じ数字になることを、検証で数えて示す。定数（重み・指数・技係数）は
表に出して、次のフェーズ以降で触れるようにしておく。

**Success Criteria**
- `src/cost.js` が独立して存在し、式・重み・定数がそこに集まっとる
- 差し替え前後で全個体のコストが一致（1件も違わん）
- 内訳（base / mv / avg）が取り出せる
- 既存の検証チェーンが全部通ったまま・`sfx_bank.js` は HEAD と一致

### Phase 2: 陣営の体力にする

**Goal**: コストが試合中に増減し、それで勝敗が決まる
**Mode:** mvp
**Depends on**: Phase 1
**Requirements**: ECON-01〜07, WIN-01〜05, VER-01, VER-02, VER-03

計画18.2 の式をそのまま入れる。

```
味方が死ぬ  → 所持コスト −（その四皇モンのコスト全額）
敵を倒す    → 所持コスト ＋（相手のコスト × min(2.0, 相手÷自分) × 0.5）
敗北        = パーティ全滅  または  所持コスト ≤ 0
8Q超え      → 判定（残り所持コスト → 与ダメージ総量）
```

**掟1（決定論）を壊さんこと**が肝。所持コストの増減は乱数を通さん。
**掟9（AIログを後回しにしない）**も効く —— いつ誰がいくら動かしたかがログに残らんと、
バランスが崩れたときに追えん。

**Success Criteria**
- 計画18.3 の計算例3つが実装でその通りの数字になる（+140 / +25 / +1.4）
- 全滅とコスト枯渇の両方で決着する。理由が分かる
- 8クォーター超えで判定に移り、残コスト→与ダメの順で決まる
- `determinismTest()` が通ったまま
- 定数が1箇所にまとまっとって触れる

### Phase 3: 見えるようにする

**Goal**: 数字の動きが画面で分かり、手応えになる
**Mode:** mvp
**Depends on**: Phase 2
**Requirements**: BAR-01〜04, VER-02, VER-03

計画18.6 ——「所持コストバーを画面上部に敵味方2本表示する。四皇モンが死んだ瞬間、
鳴き声が0.7倍速で鳴り、**コストバーがガクッと落ちる**」。

鳴き声0.7倍は既に在る（`battle.tpl.html:1314`）。そこに絵を合わせる。

**Success Criteria**
- 上部に2本出て、今の所持コストが読める
- 死んだ瞬間に落ちるのが見える。鳴き声0.7倍と揃う
- 倒したときに伸びるのが見える
- 新しい画像ファイルは1枚も増えとらん（掟4）

## 完了条件（このマイルストーン全体）

計画 Phase 15 の原文どおり:

> 高コスト編成と低コスト編成で試合をして、18.4の非対称な2つの遊び方が実際に発生する

**ここは機械では確かめられん。** 3フェーズが終わったら、にーくらが実際に戦わせて
「強い側は守りのゲーム、弱い側は攻めのゲーム」になっとるかを見る。
なっとらんかったら、定数（k・比率上限・初期値）を触って調整する。
そのために定数を1箇所にまとめてある。
