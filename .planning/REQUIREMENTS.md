# Requirements: ポケット四皇モンスター（反動と間）

**Defined:** 2026-08-19
**Core Value:** 見とる人に「**撃てんのか、撃たんのか**」が分かること。
それが分かると采配に意味が出る —— 相手が反動中なら踏み込めるし、間を取っとるなら踏み込んだ瞬間に返される。

前のマイルストーン（コスト経済・22/22 完了）は `.planning/archive/v2-コスト経済/` に控えてある。

## 発端

にーくらの指摘（2026-08-19）:

> 白くなる表示は、四皇モンを静止させながら白く点滅させるのを技のクールダウン（反動）にすべきかな。
> もちろん、常にしろく点滅するのは違うから、CDと間をわけてほしいけどね。
> **CD（反動）は、攻撃したくてもできない状態**で、**間は、攻撃できるが、回避などを行えるように
> 相手が攻撃したあと隙などを狙うため、攻撃せず、様子見などをしている状態**を間だ。

**今の実装には「間」が無い。** AIは撃てるなら撃つ（`pickMove` は撃てる技から必ず1つ選ぶ）。
だから読み合いが成立しとらん。

白い点滅は今 `charge`（溜め）に使われとる（`flash` 0.25→0.6→0.25・`loop:true`）。
にーくらの目にはそれが「反動」に見えた —— **表現と意味がずれとる**。

## v3 Requirements

### 状態を分ける（STATE）

- [x] **STATE-01**: 「反動（CD）」「間」「溜め」が内部で明示的に区別され、外から1つの値で読める
- [x] **STATE-02**: どの状態に居るか、なぜそうなったかが AI ログに残る（掟9）
- [x] **STATE-03**: 状態を入れても決定論が壊れん。同じ種で同じ結果（掟1）

### 間（MA）

- [ ] **MA-01**: AI が「撃てるが撃たん」を選べる。今は撃てるなら必ず撃つ
- [ ] **MA-02**: 間を取った理由がログに出る（相手が溜め中／自分の残りHPが薄い／相手のCDが明ける、など）
- [ ] **MA-03**: 賢さ（int）と慎重さ（caut）が間の取り方に効く。馬鹿は間を取らん、慎重な個体はよく取る
- [ ] **MA-04**: 極端に寄らん。**実戦で「間を取る個体」と「取らん個体」の両方が観測できる**
- [ ] **MA-05**: 間の最中は回避ができる（攻撃中はできん）。それが間を取る意味やけん

### 見た目（LOOK）

- [ ] **LOOK-01**: 反動（CD）＝**静止させながら白く点滅**（にーくらの指定そのまま）
- [ ] **LOOK-02**: 間＝白やない別の表現。構えとるのが分かる
- [ ] **LOOK-03**: 溜め＝`charge` から白を外し、別の表現にする。反動と見分けが付く
- [ ] **LOOK-04**: 3つが**画素で見分けられる**（目視に頼らん）
- [ ] **LOOK-05**: 新しい画像ファイルを1枚も増やさん（掟4）

### 既存を壊さん（KEEP）

にーくら:「遠隔、遠距離攻撃のアニメーションは、すでにある自作技に影響がないようにしないとね」

- [ ] **KEEP-01**: `motions` を自前で書いとる技は**1つも変わらん**（数えて示す）
- [ ] **KEEP-02**: 既定モーションの**割り当て**（分類→anim名）は変わらん。変えるのは anim の中身だけ
- [ ] **KEEP-03**: にーくらの保存個体の自作技が壊れとらん。撃てて、当たって、音が鳴る

### 検証（VER）

- [ ] **VER-01**: 3つの状態を機械で確かめる検証ツールがある
- [ ] **VER-02**: 既存の検証チェーンが全部通ったまま
- [ ] **VER-03**: `src/sfx_bank.js` が HEAD と1バイトも変わっとらん（不可触）

   バゼルギウス「灼熱弾」  遠距離  既定に乗る

**にーくらの自作技5本のうち、既定モーションに乗っとるのは2本だけ。**

そうなれば charge に乗る技はさらに減る。**壊す余地がほぼ無い**状態で手を入れられる。
