## 発端の問題

掟にこう書いてあった —— 「**近接と雷は迎撃不可**」。
分類の中に**技の名前**が混ざっとって、一般化に失敗しとる。「足元から棘が生える」技を作ったとき、
雷やないけん相殺される、では明らかにおかしい。

コードを読んだら、もっとはっきりした。相殺の対象は

```js
function isBullet(s){ return s instanceof ProjectileFX; }
function isBeam(s){   return s instanceof BeamFX; }
```

で決まっとった。**どのFXクラスが生成されたか**だけ。近接も雷も Projectile/Beam を作らんけん、
**結果として**対象外になっとっただけで、ルールとして書かれとらんかった。

にーくらの指摘は正確やった —— **雷が特別なんやのうて、雷のジェネレータが実体を飛ばさんけん**そうなる。

## 成功基準ごとの結果

### 1. 分類フィールドがあり、新技も迷わず分類できる。44技＋内蔵技すべてに付いとる — ✓ 通過

定義は速さやのうて **実体が空間を進むかどうか**。

| generator | 実体が進むか | 分類 |
|---|---|---|
| projectile / beam | **進む** | **遠距離** |
| slash | 触れて当てる | 近接 |
| lightning / aura / shatter | 進まん | 遠隔 |

**この対応は勝手に決めたもんやない。** 相殺の実装が既に使っとった区別
（`ProjectileFX`/`BeamFX`）に名前を付けただけ。だから**挙動が1ミリも変わらん**。

```
starter_moves.js  44技すべて分類済み・食い違い0・未設定0
  遠距離 24技 / 近接 11技 / 遠隔 9技
moves.js          内蔵6技に range を明示（落雷=remote、亜空切断=melee）
```

新しい技も一意に決まる例（実データ）:

```
ひのこ         projectile → 遠距離
はっぱカッター  slash      → 近接
10まんボルト   lightning  → 遠隔
りゅうのまい    aura       → 遠隔
じしん         shatter    → 遠隔     ← 雷やないが、実体が進まんけん遠隔
```

**「じしん」がこの定義の効き目。** 前の掟では判断できんかった技が、迷わず決まる。

### 2. 相殺が「遠距離か」で門前払いされ、既存の力関係は変わらん — ✓ 通過

```

aura        上がらん

```

**弾↔弾／光線↔光線／貫通の力関係は1行も触っとらん。** あれは全部「遠距離」の内側の話。
`resolveClash` の中身は無変更。変えたんは門番だけ。

`npm run verify`（4段・resolve一致36通り）が exit=0 で、**戦闘の結果が今までと同じ**ことも確認。

### 3. `fx.motions[]` が空の技に分類ごとの既定が割り当たる。棒立ちが無くなる — ✓ 通過（見た目は目視）

```
近接    attack（既定の長さ）      踏み込む
遠距離  attack（0.42秒に短縮）    前へ出す（控えめ）
遠隔    charge                    その場で溜める
```

**遠隔で腕を前に振らせん**のが肝。実体が飛ばんのに「飛ばした」ように見えると、
分類の意味と絵が食い違う。にーくらの「控えめな攻撃アニメーションを遠距離・遠隔に」という
指定に対し、**向きも分けた**（前へ出す／その場で溜める）。強度は両方とも近接より控えめ。

**新しい絵は作っとらん**（掟4：画像を増やさん）。既存の `attack`/`charge` の使い分けと長さだけ。

**目視が要るのはここ:** 実際にどう見えるか。データ上の割り当ては確認済み。

### 4. 個別の技が `fx.motions[]` で既定を上書きできる — ✓ 通過

```
上書き  anim=jump  dur=1.25   ← motions を書いた技は既定へ来ん
```

技クリエーターからの上書きは既存の仕組み（`scheduleMotions` が motions を優先）。
にーくらが言っとった「例外が現れたら手動でビルドツールで直す」がそのまま成立する。

さらに **技データに `range` を書けば導出より優先される**（検証済み）。
`range:'remote'` と書けば generator が projectile でも遠隔として扱われる。
