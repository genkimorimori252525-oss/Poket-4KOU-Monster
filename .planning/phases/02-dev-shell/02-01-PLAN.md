**2. `devshell/server.js`** — Bun のサーバー。`Bun.serve` を使う。

- `hostname: '127.0.0.1'` を**必ず指定する**。既定の全インターフェース待ち受けにしない（脅威 T-02-03）
- 設定は `import.meta.dir` から `shell.config.json` を読む。ポートは位置引数 `process.argv[2]` が
  あればそれを優先（`tools/serve.js` の `parseInt(process.argv[2] || '8765', 10)` と同じ流儀）
- ルーティング
  - `GET /` は `devshell/dashboard.html` を返す
  - `GET /__shell/ping` は `text/plain` で `ok`（launch.js の起動待ちに使う）
  - `GET /__shell/config.json` は `shell.config.json` をそのまま返す
  - それ以外は `roots` を長いプレフィックス順に照合し、該当ディレクトリから静的配信
- **パス安全チェックを root ごとに行う。** `tools/serve.js` の `if (!file.startsWith(ROOT))` を写すが、
  `dist` と `dist-dev2` のような**兄弟ディレクトリ名の接頭辞一致**を素通ししないよう、
  `resolved === rootAbs || resolved.startsWith(rootAbs + path.sep)` の形で判定する（脅威 T-02-04）
- MIME 表は `tools/serve.js` のものを土台にし、**音を足す**。
  `.html .js .json .png .css` に加えて
  `.ogg` は `audio/ogg`、`.mp3` は `audio/mpeg`、`.wav` は `audio/wav`、`.webp` は `image/webp`、
  `.svg` は `image/svg+xml`、`.ico` は `image/x-icon`、`.woff2` は `font/woff2`。
  不明拡張子は `application/octet-stream`（既存どおり）
- エラー本文は既存の流儀どおり日本語の平文。見つからないとき `'見つからん: ' + rel`（404）、
  ルート外へ出ようとしたとき `'no'`（403）。JSON にしない
- 起動ログは `console.log('devshell  http://127.0.0.1:' + port + '/')`

**4. `devshell/launch.js`** — ブラウザ探索とプロセス起動。Bun で走らせる。**CommonJS** で書き、
`module.exports = { findBrowser, CANDIDATES }` を出す（テストから直接呼べるようにする）。
`if (require.main === module) main();` で本体を走らせる。

`findBrowser()` の探索順（**すべて `fs.existsSync` だけで判定する**）:

1. 環境変数 `SHELL_BROWSER` に入っているパス（`tools/verify_*.js` の `PW_CHROMIUM` と同じ流儀）
2. `%LOCALAPPDATA%\ms-playwright\` を `fs.readdirSync` し、名前が `chromium-` で**始まる**エントリ
   （ハイフン。`chromium_headless_shell-` はアンダースコアなので自然に外れる）を降順に並べ、
   各々 `<entry>\chrome-win64\chrome.exe` の存在を見る
3. `C:\Program Files\Google\Chrome\Application\chrome.exe`
4. `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`
5. `%LOCALAPPDATA%\Google\Chrome\Application\chrome.exe`
6. `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
7. `C:\Program Files\Microsoft\Edge\Application\msedge.exe`

見つからなければ `null` を返し、本体側は「ブラウザが見つからん。SHELL_BROWSER に実行ファイルの
パスを入れて」と出して終了コード1で終わる。

**探索は存在確認だけで済ませる。ブラウザの実行ファイルをここで起動して素性を問い合わせない。**
このマシンでは GUI を立てようとして戻ってこず、実測で2分タイムアウトした（CONTEXT.md）。
この性質は本タスクの `<verify>` で「探索が1秒未満で終わること」として機械的に確かめる。

`main()` の流れ:

1. `shell.config.json` を読む
2. `fetch('http://127.0.0.1:' + port + '/__shell/ping')` を1回試す。200 が返ればサーバーはもう
   立っているので起動しない（二度押し対策）
3. 立っていなければ `Bun.spawn([process.execPath, <devshell/server.js の絶対パス>], {stdio:['ignore','inherit','inherit']})`
   で起動する（`process.execPath` は bun 自身）
4. `/__shell/ping` を 100ms 間隔で最大50回ポーリングし、200 が返るまで待つ。5秒で諦めて
   「サーバーが立ち上がらん」と出して終了コード1
5. `<repo>/.devshell/profile` を `fs.mkdirSync(..., {recursive:true})` で用意する（絶対パス）
6. ブラウザを `Bun.spawn` で起動。引数は
   `--app=http://127.0.0.1:<port>/`、`--user-data-dir=<profile の絶対パス>`、
   `--window-size=780,900`、`--no-first-run`、`--no-default-browser-check`、
   `--autoplay-policy=no-user-gesture-required`。
   最後の1つは `tools/verify_*.js` の `LAUNCH.args` と同じ。開発シェルでは操作前でも音が鳴った
   ほうが都合がよい
7. ブラウザのプロセスが終わるのを `await proc.exited` で待ち、終わったら手順3で起動したサーバーを
   `kill()` する（自分で立てた場合のみ）。**ウィンドウを閉じたら全部止まる**、が狙い

`--user-data-dir` を必ず与えることで、にーくらが普段使う Edge / Chrome のプロファイル
（Copilot・サイドバー・拡張）とは完全に別プロセス・別プロファイルになる。
