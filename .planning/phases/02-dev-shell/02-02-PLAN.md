**1. `tools/check_untouched.js`** — 素の Node CommonJS。25行程度。

各パスについて `git hash-object <path>`（作業ツリーの実際の中身のハッシュ）と

**なぜ `git status` を使わないか。** Phase 1 でこの罠を2回踏んでいる。Windows の
`core.autocrlf=true` によって git のインデックスの stat キャッシュが陳腐化し、**中身が同一なのに

実際の中身を読んでハッシュを計算するので、この偽陽性を原理的に踏まない。ゲートは中身で判定する。

出力は1行1ファイルで、末尾に `不可触 5件すべて HEAD と一致` か
`N件 変わっとる` を出す。Phase 1 の `verify_*.js` の出し方（日本語1行＋件数）に合わせる。
