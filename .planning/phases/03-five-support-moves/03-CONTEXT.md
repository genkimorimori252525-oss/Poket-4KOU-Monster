# Phase 3（補助技を入れる）の文脈

## なぜこのフェーズが要るか（測った事実）

Phase 2.1 は補助の**仕組み**を組み上げた —— `kind` / `effect` / `applySupportEffect` /
`buffValue` / `scoreMove` の「補助の値打ち」項 / 制作ツールのトグル / `verify_support.js`。

**が、その仕組みを使う技が1本も無い。** 技棚 191件を数えて `kind:"support"` は **0本**。
`aura` generator の技も 0本（Codex の作り直しで `dragon_dance_move` 等へ置き換わった）。
このままやと Phase 2.1 は「動くけど誰も乗っとらん装置」で終わる。

## 決まっとること（にーくら決定・変更不可）

### 作る5本

| 技 | generator | 対象 | 効果 | delta×dur |
|---|---|---|---|---|
| りゅうのまい | `dragon_dance_move`（**既存の専用generator**） | 自分 | `atk +22` / 16秒 | 352 |
| どくどく | `toxic_move`（**既存の専用generator**） | 相手 | `atk −20` / 18秒 | 360 |
| うずしお | `whirlpool_move`（**既存の専用generator**） | 相手 | `spd −20` / 18秒 | 360 |
| すなかけ | **新規専用**（idea棚から昇格） | 相手 | `eva −20` / 16秒 | 320 |
| 斎藤尻隠れ | **新規専用**（完全新規） | 自分 | `def +22` / 16秒 | 352 |

- **既存3本は `kind` と `effect` を足すだけ。** 専用generatorは既にあるけん、FXは作らん。
- **新規2本は専用FXクラスを新造する。** ここがこのフェーズの重い所。
- 「斎藤尻隠れ」はにーくら命名（2026-08-21）。この企画には既に尻を題材にした技がある
  （ビック尻ドロップ／`BigButtDropFX`、`tools/verify_butt_animation.js`）。その系譜に乗る。
- **数字は着手時に詰めてよい。** ただし下の `delta × dur ≳ 270` は外さんこと。

### 掟3 —— 専用generator・素材流用なし

技を作るときは**既存素材を組み合わせん**。その技のための専用クラスを作る。
汎用generatorへ落とすと「見た目だけ別名の素材流用」になる。
Codex が `REBUILT_MOVE_FX` / `REBUILT_MOVE_META` でこの形を確立しとるけん、**それに倣う**。
非流用は `tools/verify_rebuilt_moves.js` が既に検査しとる（`parts=0` を見る）。

### 採点の線 —— `delta × dur ≳ 270`

plan-check の R4 で**実測した**線。これを下回る補助技は `scoreMove` で攻撃技に負け、
**AI が一生撃たん**。データだけ増えて死ぬ ——
Phase 2.1 が防ごうとした失敗を自分で踏むことになる。5本とも満たすこと。

一般形（atk50・自分掛け・atk効果）:
`補助の値打ち / 期待ダメージ(参照技1発) = (delta/100) × dur / (cd_ref × cdScale)`

### 触ってはいかんもの

- `src/sfx_bank.js` —— 不可触（掟）
- **新しい絵は1枚も増やさん**（掟4）。FXはコードで描く
- にーくらの保存個体、および自作技 **亜空切断（`shatter`）と灼熱弾（`projectile`）**
  —— この2本は汎用generatorのままやが、**にーくらが触ってええと言うまで手を付けん**
- 内蔵6技の既定の挙動

### `spd` の注意（既に実装済み・UIとAIログに明示されとる）

`f.cd[m.id] = m.cooldown * f.cdScale` は**撃った瞬間に計算して固定される**。
つまり `spd` 効果は「**次の技から**」効き、今走っとる反動は縮まらん。

**うずしおの `spd −20` はこれを読み合いに使う技。** 「今すぐ効く技」やのうて
「次の一手を鈍らせる技」。間を取る動機になる。設計としてこれは**欠点やのうて狙い**。
