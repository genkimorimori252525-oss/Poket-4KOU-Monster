# 効果音マップ（sfx_bank.js の中身）

すべて CC0。モノラル22kHz Ogg Vorbis へ再圧縮して data URI で焼き込み済み。

音ラボ（shioumon_audio_lab.html）で、この一覧から選んで技やシステムへ割り当てる。
