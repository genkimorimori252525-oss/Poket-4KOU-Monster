# 技ネタ帳 — タイプ別10個ずつ

ポケモンの技を**下敷き**にした、技エフェクト作りのネタ帳。18タイプ × 10 = 180個。
このゲームは**配布しない**個人プロジェクトやけん、参考にするだけ。

## 読み方

「作り方」は**技クリエーターのそのままの言葉**で書いとる。開いて選ぶだけで形になる。

| 列 | 中身 |
|---|---|
| 作り方 | 飛び道具 / 光線 / 斬撃 / 雷 / オーラ / 空間割れ のどれで組むか |
| パレット | プリセット名。合うのが無いときは色を直に書いとる |
| ねらい | 触るべきツマミと、素材（重ねるエフェクト）の案 |

**「＋素材」と書いてあるやつは2段構え。** 本体を撃ったあと、演出素材で2枚目を重ねる。
亜空切断（斬撃＋空間割れ）と同じ組み方。

## メモ

- パレットのプリセットは 炎/水/雷/毒/氷/闇/草/鋼 の8つ。表で色を直に書いとるのは、
  プリセットに無い色。4色は**左＝中心（明るい）→ 右＝外周（暗い）**の順で入れる。
- 「素材で連射」は、本体を1発だけにして、演出素材で同じものを +0.05〜0.10秒ずつ
  ずらして並べるのが早い。**位置も少しずつずらすと散弾らしくなる。**
- 作った技は**技ライブラリに保存**しとけば、別の四皇モンにも渡せる。
- タイプ一致ボーナスは ×1.25 だけ。**相性表は作らん**（計画1.2(b)）。
  タイプは分類でしかないけん、技をどのタイプに置くかは見た目で決めてよか。
