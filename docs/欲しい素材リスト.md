# 欲しい素材リスト（新しい generator の発注書）

**これは他の AI に渡して実装してもらうための発注書。**
「素材（＝技クリエーターで選べるエフェクトの種類）」を新しく作るときの、
**何が欲しいか・なぜ要るか・どう繋げば壊れんか**を全部ここに書いた。

現在の素材は6つだけ：`projectile` `beam` `slash` `lightning` `aura` `shatter`。
既存の6つで組む方法は `docs/技演出マニュアル.md`。**この文書はその6つでは届かん所の話。**

## 2. ⚠ 先に直すべきバグ —— オーラ技は**ダメージが0**

素材を足す前に、これを知っといてほしい。**上の21本は、今のままでは技として成立せん。**

`src/battle.tpl.html:1622` と `1633-1638`：

```js
const support = m.fx.generator==='aura';        // ← aura は無条件で「補助技」
const from=muzzle(f), to = support ? target(f) : target(foe);   // ← 狙い先が自分になる
...
const sh = spawnFX(spec, from, to, builtOf(m.fx), ()=>{
  if(support){ box.play(f.name+'の　きあいが　たかまった！'); return; }   // ← ここで返る
  ...
  applyHit(f, foe, m, sh.powerMul);             // ← aura は絶対にここへ来ん
});
```

つまり **generator が aura というだけで**：

1. 狙い先が相手やのうて**自分**になる（「相手に置く」と書いた21本が全部自分の足元に出る）
2. `applyHit` が呼ばれん＝**威力をいくつ設定してもダメージ0**
3. その代わりの補助効果も**無い**。`きあいが たかまった！` は
   `battle.tpl.html` 全体で**この1か所にしか出てこん**。能力を上げる処理はどこにも無い。

**今の aura 技は、ダメージも補助効果も無い、絵だけの技。**

直し方は2つ。どっちを採るかはにーくらの判断：

- **(a) `support` の判定を generator やのうて技データで持つ** —— `battle.moveKind:'support'` を足す。
  そうすれば aura を攻撃にも補助にも使える。**下の素材を足すなら必ずこれが要る**
  （新しい素材 `field` は攻撃技やけん、generator で判定しとると同じ穴に落ちる）。
- **(b) 補助効果を実装する** —— 能力変化の仕組みそのものが無いけん、これは別のフェーズの話。

**素材を発注する前に (a) をやること。** やらんと、新しく作った素材も同じ理由で無力化される
可能性がある（実装者が `support` の判定に手を入れてしまうと厄介）。

## 3. 素材を足すときの契約（実装者が必ず守ること）

**ここを外すと、絵は出るのに戦闘だけ壊れる、という一番厄介な形になる。**

### 3-1. 登録先は9か所。1つでも抜けると動かん

| # | ファイル | 場所 | 何を足すか |
|---|---|---|---|
| 1 | `src/fx_core.js` | `DEFAULTS`（837行） | `X:{generator:'X', ...既定値, impact:{...} or 省略}` |
| 2 | `src/fx_core.js` | クラス定義 | `class XFX extends BaseFX { update(dt){} draw(g){} }` |
| 3 | `src/fx_core.js` | `spawnFX()`（690行） | `case 'X': return new XFX(sp,from,to,built,onHit);` |
| 4 | `src/fx_core.js` | `buildEffect()`（223行） | 焼きコマが要るなら `if(sp.generator==='X') o.body=...` |
| 5 | `src/fx_core.js` | `TRAVELS`（745行） | **実体が飛ぶ素材だけ** `X:1` を足す |
| 6 | `src/movelab.js` | `SCHEMA`（55行） | `X:[['key','rng',min,max,step,'単位'], ...]` |
| 7 | `src/movelab.js` | `LABEL`（18行） | 新しいキーの日本語名 |
| 8 | `src/movelab.js` | `GEN_JP` / `GEN_DESC`（37-44行） | 表示名と1行説明 |
| 9 | `src/move_range.js` | `BY_GENERATOR`（38行） | `X:'melee' \| 'ranged' \| 'remote'` |

**9番を忘れると `rangeOf()` が既定の `'ranged'` を返す**（`move_range.js:45`）。
遠距離扱いになると相殺の土俵に乗る判定に入ってしまう。**必ず明示すること。**

### 3-2. 相殺（迎撃）に乗せるかどうか

相殺の門番は**クラスで見とる**（`src/battle.tpl.html:1719-1722`）：

```js
function isRangedShot(s){ return (s instanceof ProjectileFX) || (s instanceof BeamFX); }
```

つまり **`ProjectileFX` / `BeamFX` を継承せん限り、新しい素材は相殺されん**。
今回の発注はすべて `remote`（実体が空間を進まん）やけん、**ここは触らんでよい**。
逆に「飛んでいく新素材」を作るときは、ここに足さんと相殺から漏れる。

### 3-3. クラスの決まり

`BaseFX`（`fx_core.js:321`）を継承すると、以下が使える状態で渡ってくる：

```js
this.sp        // 技データ（パラメータ一式）
this.f         // 撃った人の座標 {x,y}
this.t         // 狙い先の座標 {x,y}
this.b         // buildEffect() が焼いたコマ
this.rng       // RNG（種は sp.seed+77）。★ 乱数はこれ以外を使うな
this.ts        // timeScale（0.05〜4）
this.time      // 経過秒（stepCommon が進める）
this.parts     // Particle の配列（stepCommon が更新・寿命切れを掃除）
this.state     // 'run' → 終わったら 'dead' を自分で入れる
this.doHit()   // 当たった瞬間に呼ぶ。画面演出の impact とダメージがここで走る
```

`update(dt)` は**必ずこの形**で書く：

```js
update(dt){
  dt *= this.ts;              // ① 技全体の速さ。忘れると timeScale が効かん
  this.stepCommon(dt);        // ② 時間を進める・粒を更新する
  ...本体の処理...
  if(当たった条件) this.doHit();
  if(終わった条件) this.state='dead';
}
```

`draw(g)` は 2D canvas。`g.globalAlpha` を触ったら**必ず 1 に戻す**（他の描画に漏れる）。

### 3-4. 決定論の縛り（掟1・2）—— 破ると戦闘が壊れる

- **`Math.random()` 禁止。** 揺らぎは `this.rng` から。同じ技は誰が撃っても同じ絵にならんといかん。
- **`setTimeout` / `requestAnimationFrame` 禁止。** 遅延は固定タイムステップの `dt` で数える。
  遅れて出す仕組みは `DelayFX`（`fx_core.js:718`）が既にある。
- **`Date.now()` 禁止。**

### 3-5. 絵を増やさん（掟4）

**画像ファイルを追加せん。** 全部その場で canvas に描く。既存の素材も全部そうしとる。

### 3-6. 動作確認

```bash
node build.js --dev
```
→ `dist-dev/lab.html`（技ラボ）を開いて、新しい素材が選択肢に出て、
スライダが全部効いて、色ボタンでパレットが変わることを見る。

## 4. 欲しい素材（優先度順）

### 【1】 `field` —— 領域・嵐・霧　★最優先（21本を解禁）

**何ができるか**：ある場所を**面で覆う**。渦を巻く／漂う／横に流れる／降ってくる。
実体が飛ばず、その場に一定時間留まる。

**なぜ要るか**：今この21本は全部 `aura`（自分の足元から輪が昇るだけ）に押し込まれとる。
`aura` は「1点から上へ昇る輪」しか描けん。**ふぶきも うずしおも かぜおこしも 同じ絵になる。**
しかも第2節のとおり aura はダメージが0。

**分類**：`remote`（実体が空間を進まん。迎撃されん）

**パラメータ**（`SCHEMA` にそのまま書ける形）

| キー | 日本語 | 型・範囲 | 既定 | 意味 |
|---|---|---|---|---|
| `shape` | 動き方 | sel `swirl`/`drift`/`sweep`/`fall` | swirl | 渦／漂う／横に流れる／降る |
| `size` | 広がりの幅 | rng 40〜340 px | 140 | |
| `height` | 広がりの高さ | rng 10〜200 px | 70 | 低く広く＝地を這う。高く＝嵐 |
| `density` | 粒の数 | rng 4〜120 粒 | 40 | |
| `speed` | 粒の速さ | rng 5〜200 | 60 | |
| `spin` | 渦の回り | rng −8〜8 | 2 | 0＝回らん。マイナスで逆回り |
| `grain` | 粒の大きさ | rng 1〜6 px | 2 | |
| `duration` | 出とる長さ | rng 0.4〜4.0 秒 | 1.4 | |
| `fade` | 縁のぼけ | rng 0〜1 | 0.4 | 高いほど霧っぽい |

**`impact`**：持たん（`impact:null`）。当たり判定は開始0.15秒後に `doHit()` を1回。

**この1つで作れるようになる技（技ネタ帳の実名）**

| shape | 技 |
|---|---|
| `swirl` 渦 | うずしお・すなじごく・ぼうふう・リーフストーム・ダイヤストーム・むしのさざめき |
| `drift` 漂う | どくどく・ヘドロウェーブ・あやしいひかり・あまえる・きんぞくおん・むしのていこう |
| `sweep` 横に流れる | なみのり・かぜおこし・じならし・バークアウト・チャームボイス・こごえるかぜ |
| `fall` 降る | ふぶき・いとをはく・テレキネシス（向きを逆に） |

### 【2】 `erupt` —— 噴出・柱・隆起（5本＋今後の地面系）

**何ができるか**：**地面から立ち上がる**もの。火柱・水柱・石柱・根・棘。
`lightning` の `fromSky:false` が今その代役やが、雷はギザギザに折れる線やけん、
**柱には見えん**（`jag` を下げても稲妻の骨格が残る）。

**分類**：`remote`

| キー | 日本語 | 型・範囲 | 既定 | 意味 |
|---|---|---|---|---|
| `count` | 本数 | rng 1〜8 本 | 1 | |
| `width` | 太さ | rng 4〜60 px | 18 | |
| `height` | 高さ | rng 40〜300 px | 140 | |
| `rise` | 立ち上がる速さ | rng 0.08〜1.2 秒 | 0.25 | 短い＝突き上げ。長い＝せり上がり |
| `tip` | 先の形 | sel `point`/`round`/`leaf`/`split` | point | 尖／丸／葉／裂ける |
| `spread` | 本どうしの間隔 | rng 0〜120 px | 30 | |
| `stagger` | 順に出る間隔 | rng 0〜0.4 秒 | 0.08 | 0＝同時。値を入れると波打つ |
| `hold` | 立ったまま残る | rng 0.1〜1.5 秒 | 0.4 | |
| `debris` | 根元から散る粒 | rng 0〜60 | 24 | 土煙・飛沫・火の粉 |

**`impact`**：持つ（先端に着弾の絵）。

**解禁される技**：ふんか（tip:split・炎）・たきのぼり（tip:round・水）・
ハードプラント（tip:leaf・count 5）・だいちのちから（tip:point・width 太）・

### 【3】 `burst` —— 爆発（10本）

**何ができるか**：膨らむ火球＋衝撃波の輪＋煙。多段にもできる。

**なぜ要るか**：今は `shatter`（ガラスが割れる）で代用しとる。
ガラスの破片は**平面が割れて破片が回りながら飛ぶ**絵で、爆発の**膨らむ**動きが無い。
だいばくはつ・ブラストバーン が同じ「ガラス割れ」になっとる。

**分類**：`remote`

| キー | 日本語 | 型・範囲 | 既定 | 意味 |
|---|---|---|---|---|
| `size` | 最大の大きさ | rng 40〜340 px | 120 | |
| `expand` | 膨らみきるまで | rng 0.05〜0.6 秒 | 0.18 | 短いほど鋭い炸裂 |
| `rings` | 衝撃波の輪 | rng 0〜5 | 1 | 0＝ただの火球 |
| `smoke` | 煙の量 | rng 0〜120 粒 | 40 | |
| `stages` | 何段の爆発か | rng 1〜3 段 | 1 | |
| `interval` | 段の間隔 | rng 0.05〜0.5 秒 | 0.15 | |
| `linger` | 煙が残る時間 | rng 0.2〜2.0 秒 | 0.8 | |

**`impact`**：持たん（自分が着弾の絵を兼ねる）。

**解禁される技**：だいばくはつ（stages 3・size 最大）・ブラストバーン・ナイトバースト・
ミストバースト・ばくれつパンチ（着弾の素材として）・だいもんじ・アシッドボム・ヘドロばくだん

> ⚠ `shatter` は**残す**。じしん・じわれ・サイコキネシス・ポルターガイスト は
> 「割れる」が正しい絵。`burst` は割れやのうて**膨らむ**もの。役割が違う。

### 【4】 `drain` —— 吸収・還流（2本＋今後の回復系）

**何ができるか**：**2点を結んで粒を流す**。相手から自分へ吸い取る／自分から相手へ送る。

**なぜ要るか**：今は「素材でオーラを自分に」で代用しとるが、
それは自分の足元に輪が出るだけで、**相手から流れてくる**絵にならん。
そして `drain` は**2点を結ぶ唯一の素材**になる。既存6つにこの表現は1つも無い。

**分類**：`remote`
**特記**：`TRAVELS` に登録する（行き先が要る素材）。`anchor` の**反対側**から粒が飛んでくる
（`partPoints()`（`fx_core.js:746`）が既にこの仕組みを持っとる。そこに乗せるだけでよい）。

| キー | 日本語 | 型・範囲 | 既定 | 意味 |
|---|---|---|---|---|
| `count` | 粒の数 | rng 6〜80 | 26 | |
| `speed` | 流れる速さ | rng 60〜500 px/s | 220 | |
| `curve` | 弧の反り | rng −80〜80 px | −30 | 0＝直線。値を入れると弧を描く |
| `rate` | 粒を出す間隔 | rng 0.02〜0.4 秒 | 0.06 | |
| `duration` | 出とる長さ | rng 0.3〜2.5 秒 | 0.9 | |
| `grain` | 粒の大きさ | rng 1〜6 px | 3 | |
| `reverse` | 向きを逆に | bool | false | 自分→相手へ送る（毒・呪い） |

**解禁される技**：ドレインパンチ・ドレインキッス・きゅうけつ・つきのひかり（自分に集める）

## 5. 素材やのうて「仕組み」で足すべきもの

新しいクラスを書くより安く、効きが大きい2つ。**素材より先にこっちをやってもよい。**

### 5-1. `parts` に `repeat` / `every` を足す（13本が解決）

今は連射を作るのに**同じ素材を手で4〜5個並べて `off` を 0.05 ずつずらしとる**。
技ネタ帳に「素材で+0.05秒ずつ5連」と書いてある13本が全部これ。
技データが膨らむし、あとで調整するとき5か所直さんといかん。

```jsonc
{ "generator":"projectile", "at":"fire", "off":0,
  "repeat": 5,          // 何回出すか（1〜12）
  "every":  0.05,       // 何秒おきか（0.02〜0.6）
  "jitter": 8 }         // 出る位置のばらけ px（0〜60）※ rng で決める。Math.random 禁止
```

**実装は `spawnPart()`（`fx_core.js:758`）1か所で済む。**
既に `DelayFX` で遅延を作る仕組みがあるけん、`repeat` 回ぶん `DelayFX` を積むだけ。
技ラボ側は `movelab.js` の parts 編集（300-450行）にスライダを3本足す。

**解禁**：スピードスター・トライアタック・バブルこうせん・タネマシンガン・つららばり・
ミサイルばり・がんせきふうじ・いわなだれ・ロックブラスト・たたりめ・スケイルショット・
りゅうせいぐん・ドラゴンアロー

### 5-2. パレットを5つ足す（20本が色を直書きしとる）

`PALETTES`（`fx_core.js:825`）は今8つ。**4段の色を書き足すだけ**で技ラボの色ボタンも自動で増える。
規則は「[0]白か白寄り → [1]明るい固有色 → [2]濃い固有色 → [3]ほぼ黒」（詳細は技演出マニュアル節4）。

| 追加したい | 用途 | 案 |
|---|---|---|
| `土` | じめん全般。今は「鋼」に逃がしとる | `#fff4e0` `#e0b878` `#a06830` `#3a2010` |
| `木` | くさの物理系（ウッドハンマー等） | `#f8f0d8` `#c8a870` `#806038` `#2a1c10` |
| `金` | ゴッドバード・せいなるほのお・パワージェム | `#ffffff` `#ffe8a0` `#e0a820` `#6a4400` |
| `桃` | フェアリー全般。今は「毒」に逃がしとる | `#ffffff` `#ffd8e8` `#ff88b8` `#8a2050` |
| `虹` | オーロラビーム・シグナルビーム | `#ffffff` `#a8f0d0` `#88b8ff` `#7048c0` |

## 6. 優先順（迷ったらこの順）

| 順 | やること | 効き | 手間 |
|---|---|---|---|
| 0 | **`support` 判定を generator から技データへ移す**（第2節） | 21本が技として成立する | 小 |
| 1 | `parts` に `repeat`/`every`（5-1） | 13本 | 小 |
| 2 | パレット5つ追加（5-2） | 20本 | **極小** |
| 3 | **素材 `field`** | 21本 | 大 |
| 4 | 素材 `burst` | 10本 | 中 |
