# 発注書：斬撃と光線に「形」を5種ずつ足す

**渡す相手**：Codex（リポジトリを読めて、コマンドも走らせられるコーディングAI）
**やってもらうこと**：`slash` と `beam` に `style` パラメータを足して、5つの形を描き分ける
**やってもらわんこと**：画像ファイルの生成・追加（理由は第1節）

> ⚠ このリポジトリに `AGENTS.md` は無い。Codex は `CLAUDE.md` を自動では拾わん可能性があるけん、
> **プロンプトで明示的に読ませる**（第8節でそうしとる）。

## 1. まず前提 —— このゲームのエフェクトに画像素材は無い

`src/fx_core.js` に画像を読む処理は**1つも無い**（`new Image` / `.png` / `img.src` すべて0件）。
エフェクトは全部その場で canvas に描いとる。これは手抜きやのうて設計。

**PNG が使えん技術的な理由**（掟の話より先にこっちが効く）：

1. **色は描く瞬間に決まる。** 4段パレットを**番号で**引いとる。
   ```js
   let idx = Math.min(P-1, Math.floor(t*P));          // genSlashFrames:199
   d[o]=pal[idx][0]; d[o+1]=pal[idx][1]; d[o+2]=pal[idx][2];
   ```
   ```js
   pxLine(g, px,py, jx,jy, w, P[li]);                 // BeamFX.draw:446
   ```
   灼熱弾と水弾は**同じ generator でパレットだけ違う**。PNG は色が焼き付いとるけんこれができん。
   全部の組み合わせを画像で持つと、斬撃だけで 8パレット × 5形 × 14コマ = **560枚**。
2. **大きさが可変。** `size` はスライダ 24〜320px。焼くときにその寸法で作り直しとる。
   PNG は1解像度しか無い。拡大すればドットが潰れる。
3. **技ごとに違う揺らぎ。** 縁のギザつきは `RNG(sp.seed)` から作る。PNG は毎回同じ絵になる。
4. **光線はそもそもコマを焼かん。** 毎フレーム `hash3(i,li,tick)` で揺らして直に描いとる。
   コマという単位が存在せんけん、画像の渡し先が無い。

> **画像生成AIの正しい使い道**：下絵として使うこと。
> 「螺旋を描く光線はどう見えるべきか」を絵に出させて**見本**にし、それを見ながらコードを書く。
> 出した画像はリポジトリに入れん。これなら画像生成の強みがそのまま活きる。

## 2. 今どうなっとるか

**見た目の選択肢を持っとるのは飛び道具だけ。**

```js
projectile: [['shape','sel',['orb','shard','ring','bolt']], ...]   // movelab.js:56
```
`genBodyFrames()`（`fx_core.js:89-97`）が `sp.shape` で分岐して描き分けとる。**この形を真似する。**

一方 `slash` と `beam` は**数字のツマミしか無い**。太さや連撃数は変えられても、
**形そのものは1種類**。結果、技ネタ帳（`docs/技ネタ_タイプ別.md`）では：

- **斬撃52本**（全体の29%）が全部「弧を描く三日月」。からてチョップ も ドラゴンクロー も DDラリアット も同じ形
- **光線23本**（13%）が全部「まっすぐ伸びる線」。かえんほうしゃ（噴射）も れいとうビーム（直線）も
  ハイドロポンプ（押し出す圧）も同じ形

## 3. 実装の対象（2か所。作りが違うけん注意）

### 3-1. 斬撃 `slash` —— **コマを焼く**方式

`genSlashFrames(sp)`（`fx_core.js:159-221`）が **14コマ**を作って返す。
各コマは `mkCv(S,S)` のオフスクリーン canvas に **ImageData へ1ピクセルずつ書き込む**。

今の形の作り方（これが `style:'arc'` になる）：

```js
const S=Math.max(24,sp.size|0), N=14;
const half=(sp.arcDeg*Math.PI/180)/2;     // 弧の半分の角度
const R=S/2-3;                            // 弧の半径
const wmax=Math.max(1.2,(sp.thickness||8)/2);
const rng=new RNG(sp.seed||1);            // ★ 乱数はこれだけ
// 28点の縁ノイズを先に作る（コマ間で一貫させるため）
for(let i=0;i<NA;i++) noise.push(1+(rng.next()-0.5)*2*jit);

for(let f=0; f<N; f++){
  const p=f/(N-1);
  const lead=Math.min(1, Math.pow(Math.max(0,p)/0.42, 0.62));  // 先端が走る
  const tail=Math.max(0, (p-0.52)/0.48);                       // 後端が追う
  const fade=p<0.72?1:Math.max(0,1-(p-0.72)/0.28);             // 最後に消える
  // 極座標で「a0〜a1 の角度・半径Rの帯」を塗る
  // 帯の太さ w = wmax * sin(π*uv)^taper  ← 両端が細くなって三日月になる
  // 色は dist（帯の中心からの距離）を 0〜1 にして palette の番号に変換
}
```

**分岐を入れる場所**：`for(let f=0;f<N;f++)` の中の塗りつぶし部分。
`sp.style` で形ごとに別の関数へ振り分ける。**`lead` / `tail` / `fade` の時間の作りは全形で共通に保つ**
（走り抜けてから消える、という動きは斬撃の共通の呼吸やけん）。

### 3-2. 光線 `beam` —— **毎フレーム直に描く**方式

`BeamFX.draw(g)`（`fx_core.js:420-452`）。コマを焼かん。

```js
draw(g){
  const s=this.sp, P=s.palette;
  if(this.time < s.charge){ /* 溜め中：3枚の円を重ねる */ return; }
  const ext=this.extent();                 // 0〜1。どこまで伸びたか（相殺で途中で止まる）
  const ex=this.f.x+(this.t.x-this.f.x)*ext, ey=...;
  const ang=Math.atan2(ey-this.f.y, ex-this.f.x)+Math.PI/2;   // 線に垂直な向き
  const tick=Math.floor(this.time*24);     // ★ 時間も量子化しとる（決定論のため）
  for(let li=P.length-1; li>=0; li--){     // 外側（暗い色）から内側（白）へ
    const w=Math.max(1, Math.round(s.width*(li+1)/P.length));  // 外が太く芯が細い
    for(let i=1; i<=s.segments; i++){
      const jit=(hash3(i,li,tick)-0.5)*s.waver*(li+1)*(i===s.segments?0.2:1);
      pxLine(g, px,py, jx,jy, w, P[li]);
    }
  }
  g.globalAlpha=1;                         // ★ 必ず戻す
  this.drawImpact(g, this.t.x, this.t.y);
}
```

**分岐を入れる場所**：`draw()` の中、`ext`/`ex`/`ey`/`ang` を出したあと。
**`extent()` と `endPoint()` は絶対に触らんこと** —— 相殺（光線どうしの押し合い）が
`this.limit` を通してここに割り込んどる。形を変えても「どこまで伸びたか」の計算は共通。

## 4. 欲しい5つの形

### 斬撃 `slash.style`

| 値 | 名前 | 見た目 | 使う技（技ネタ帳より） |
|---|---|---|---|
| `arc` | 弧 | **今の形。三日月。既定値** | たいあたり・きりさく・アイアンテール ほか |
| `cross` | 十字 | 2本の弧が直交して交わる。交点が白く抜ける | クロスポイズン・シザークロス・かみくだく |
| `thrust` | 突き | 弧やのうて直線の楔。先が鋭く根元が太い。`arcDeg` は楔の開き角に読み替える | からてチョップ・メガホーン・ドリルくちばし |
| `fan` | 扇 | 弧を `count` 本の細い刃に分割し、扇状に開いて並べる | はっぱカッター・エアカッター・イカサマ |
| `spiral` | 螺旋 | 弧が中心へ巻き込む渦。半径が角度とともに縮む | じゃれつく・げきりん・インファイト |

### 光線 `beam.style`

| 値 | 名前 | 見た目 | 使う技 |
|---|---|---|---|
| `straight` | 直線 | **今の形。既定値** | れいとうビーム・ナイトヘッド・ラスターカノン |
| `wave` | 波打ち | 中心線が sin 波で上下に振れる。`waver` が振幅、`segments` が波の数 | りゅうのはどう・あくのはどう・シグナルビーム |
| `twin` | 二条 | 平行な2本。間隔は `width` に比例 | ラスターパージ・パワージェム |
| `spiral` | 螺旋 | 2本が中心軸のまわりを巻きつきながら伸びる | ハイドロポンプ・でんじほう・メテオビーム |
| `cone` | 扇状 | 根元が細く先が広がる噴射。**線やのうて噴き出し** | かえんほうしゃ・しおふき・オーバーヒート |

## 5. 絶対条件（守らんと戦闘が壊れる）

1. **`Math.random()` 禁止。** 乱数は `new RNG(sp.seed)` か `hash3(a,b,c)` だけ。
   同じ技は誰が撃っても寸分同じ絵にならんといかん（決定論チェックが落ちる）。
2. **`setTimeout` / `Date.now()` / `requestAnimationFrame` 禁止。** 時間は渡ってくる `dt` と `this.time` だけ。
3. **色は必ずパレットの番号で引く。** `sp.palette` は4色の配列。長さを決め打ちせず `P=pal.length` で書く。
   色を直接書かない（`'#ff0000'` みたいなリテラルを入れない）。
4. **画像ファイルを追加しない。** 全部 canvas に描く。
5. **`style` が無い技は今までどおりの形になること。**
   `const style = sp.style || 'arc'`（beam は `'straight'`）。
   **既存の技データを1本も壊さんこと**（`data/moves/library.json` に手作りの技が入っとる）。
6. **`g.globalAlpha` を触ったら必ず 1 に戻す。** 他の描画に漏れる。
7. **`extent()` / `endPoint()` / `doHit()` / `state` の扱いを変えない。** 相殺とダメージがここに繋がっとる。
8. **既存の形（`arc` / `straight`）の見た目を変えない。** リファクタのついでに直さんこと。

## 7. 確認のしかた

### 7-1. Codex にやらせること

Codex はコマンドを走らせられるけん、**確認まで込みで頼む**。

1. `node build.js --dev` が通ること
2. **`tools/verify_style.js` を新規に書くこと。** このリポジトリには verify 系のスクリプトが
   14本あって作法が決まっとる（`tools/verify_look.js` が一番近い手本）：
   - Playwright で `dist-dev/` を開く
   - スクリーンショットを `tools/_style-shot.png` に出す
   - NG なら**終了コード1**で落ちる
   - `PW_CHROMIUM` 環境変数で Chromium のパスを差し替えられるようにする
3. `node tools/verify_style.js` を**実際に走らせて通してから**報告すること

`verify_look.js` の冒頭に、このプロジェクトの検証の考え方がそのまま書いてある：

> 絵の話やけん「見れば分かる」で済ませたくなるが、それやと次に誰かが数字を触ったとき気付けん。
> **キーフレームの値と実際の描画の両方を数える。**

なので `verify_style.js` も目視やのうて**数える**：

- 形ごとに、描画されたピクセル数が **0でない**（描き忘れの検出）
- **隣の形とピクセルが一致せん**（＝「見分けが付く」の機械的な言い換え）
- `style` 未指定のときの出力が、`style:'arc'` / `style:'straight'` と**完全一致**する（後方互換）

### 7-2. にーくらが目で見ること

`_style-shot.png` に10個の形が1枚に並ぶけん、**それを見るだけで済む**（技ラボで10回クリックせんでよい）。

1. 5つとも**はっきり見分けが付く**（似とったら、その形だけ作り直させる）
2. `dist-dev/lab.html` で形を変えても他のスライダ（大きさ・太さ・連撃数・うねり）が全部効く
3. パレットを切り替えると5つとも色が変わる
