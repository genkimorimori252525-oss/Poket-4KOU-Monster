## 0. 技は「4つの層」でできとる

1本の技は、この4層の重ね合わせ。**どの層に何を置くかが演出設計そのもの**。

| 層 | 置き場所 | 何ができるか | タイミング | ずらせるか |
|---|---|---|---|---|
| **本体** | `fx`（generator 1つ） | 技の主役。弾・光線・斬撃・雷・オーラ・空間割れ | 発射〜着弾 | — |
| **素材** | `fx.parts[]` | 本体に重ねる追加エフェクト。**何個でも** | cast / fire / impact | **できる**（`off` 秒） |
| **画面** | `fx.screen{}` | 暗転・閃光・点滅・色被せ・揺れ・走査線 | cast / impact のみ | **できん** ⚠ |
| **本人の動き** | `fx.motions[]` | 撃った四皇モン自身のアニメ | cast / fire / impact | **できる**（`off` 秒） |
| **音** | `audio[]`（fx の外） | 効果音のタイムライン | cast / fire / impact | **できる**（`off` 秒） |

「本体1つ」で作ろうとするな。**主役1つ＋素材2〜4つ＋画面2〜5つ＋音3〜5つ**が、
既に手で作られとる技（亜空切断）の実際の構成。

## 1. 時間の骨格 —— cast / fire / impact

これを間違えると全部ズレる。`src/battle.tpl.html:1605-1645` の実装がすべて。

```
  ┌── cast ───────────┐┌── fire ──→ ･･･ 飛翔 ･･･ →── impact ──┐
  構えに入る            撃つ                          当たる
  ・motions at:'cast'   ・CD開始（＝反動の始まり）      ・screen at:'impact'
  ・audio   at:'cast'   ・motions/audio/parts at:'fire' ・motions/audio/parts at:'impact'
  ・parts   at:'cast'   ・本体 fx が生まれる            ・ダメージ計算
                        ・screen at:'cast' ← ここ！ ⚠
  長さ＝ move.cast × castScale        長さ＝可変（後述）
```

### ⚠ 落とし穴1：`screen.at:'cast'` は「構え」やのうて「発射」に出る

`SCREEN.trigger(sp.screen,'cast')` は `BaseFX` のコンストラクタの中（`fx_core.js:329`）。
`BaseFX` が生まれるんは `launch()` の中（`battle.tpl.html:1633`）＝**発射の瞬間**。

つまり **`at:'cast'` の意味が層によって違う**：

- `parts` / `motions` / `audio` の `at:'cast'` → **構えに入った瞬間**（`battle.tpl.html:1614-1616`）
- `screen` の `at:'cast'` → **撃った瞬間**（構えが終わったあと）

技ラボの UI が `screen` の選択肢を「技を出した時」と書いとるんは、実装としては正しい。
**溜めの最中に画面を暗転させたいなら `screen` では届かん。**
`parts` に暗い素材を `at:'cast'` で置くしかない。

### ⚠ 落とし穴2：fire → impact の長さは個体ごとに変わる

弾速は技やのうて**撃った個体の素早さ**で決まる（`battle.tpl.html:1626-1628`、`f.shotScale`）。
構えの長さも個体ごと（`f.castScale`）。だから：

> **「発射の 0.4 秒後」を狙った演出は当てにならん。**
> 着弾に合わせたいものは必ず `at:'impact'` に置く。`off` は「その瞬間からの微調整」にだけ使う。

近接（slash）と遠隔（lightning / aura / shatter）は実体が飛ばんけん fire→impact がほぼ0。
遠距離（projectile / beam）だけが伸び縮みする。

### `timeScale`

`fx.timeScale`（0.05〜4、既定1）で技全体の速さを伸び縮みできる（`fx_core.js:328`）。
素材の `off` も一緒に伸び縮みする（`fx_core.js:768`）。
**「重い技」を作るときは各パラメータを個別に遅くするんやのうて、`timeScale` を 0.8 にする方が崩れん。**

## 2. 生成手順（この順でやる）

技を1本作るときは、必ずこの順。順番が意味を持つ——**戦闘値が先、絵は後**。
絵から入ると「見た目は派手やが弱い」「地味やが壊れとる」が生まれる。

### 手順1. 戦闘値を決める

`{ type, power, cast, cooldown, range, tags }`。
`range` は generator から自動で決まる（`move_range.js:38-45`）けん、**generator の選択＝分類の選択**。

| generator | 分類 | 相殺の土俵 | 意味 |
|---|---|---|---|
| `projectile` | 遠距離 | **乗る** | 実体が空間を進む。撃ち落とせる |
| `beam` | 遠距離 | **乗る** | 実体が伸びる。押し合いになる |
| `slash` | 近接 | 乗らん | 触れて当てる。間に空間が無い |
| `lightning` | 遠隔 | 乗らん | 落ちる。空間を横切らん |
| `aura` | 遠隔 | 乗らん | 自分から出る。飛ばさん |
| `shatter` | 遠隔 | 乗らん | 着弾点で割れる。進まん |

威力の天井は**ダメージ式から逆算**する：

```
damageOf = power × (0.5 + atk/100) × 100/(100+def)     … 攻50/防50 で power × 0.667
maxHP    = 40 + hp × 1.6                               … 体力50 で 120
```
（`battle.tpl.html:1205-1209`、`battle.tpl.html:429`）

| 威力 | 攻50/防50 の一撃 | 何発で落ちるか |
|---|---|---|
| 22（水弾） | 15 | 8発 |
| 34（落雷） | 23 | 5発 |
| 44（亜空切断） | 29 | 4発 |
| 62 | 41 | 3発 |
| **84** | **56（HPの47%）** | **2発ちょい** ← 天井 |

84を超えると「撃った者勝ち」になって読み合いが死ぬ。**上げるな。**

### 手順2. 溜めと CD を決める

内蔵6技に合うよう較正した式（内蔵6技は戦闘の土台。STATE.md が「残す」と書いとる）：

```
cast     = clamp( (0.05 + 0.0115 × power) × 分類係数, 0.15, 1.30 )
cooldown = clamp( (0.60 + 0.0750 × power) × 分類係数, 1.30, 7.00 )

分類係数   近接 cast×0.75 cd×1.15 ／ 遠距離 cast×1.00 cd×0.90 ／ 遠隔 cast×1.45 cd×1.30
```

⚠ **clamp は分類係数を掛けた「後」**。先に clamp すると遠隔の特大技が CD 7.8秒まで伸びて、
1試合に2回しか撃てん技になる。天井は 7.0秒。

係数の理由は**その分類が何を免除されとるか**：

- 遠距離＝相殺で消される危険を負う → **割引**
- 近接＝迎撃されん。ただし距離を詰める必要がある → 標準＋
- 遠隔＝迎撃されず空間も進まん。一番強い → **一番高い**。
  そして遠隔の溜めが長いんは、**溜めだけが唯一の対抗手段**やけん。

突き合わせ（式が土台からズレとらんかの確認）：

| 技 | 威力 | 分類 | 実際 溜め/CD | 式 溜め/CD |
|---|---|---|---|---|
| 水弾 | 22 | 遠距離 | 0.24 / 1.9 | 0.30 / 2.0 |
| 灼熱弾 | 26 | 遠距離 | 0.30 / 2.4 | 0.35 / 2.3 |
| 三連爪 | 30 | 近接 | 0.18 / 2.8 | 0.30 / 3.3 |
| 落雷 | 34 | 遠隔 | 0.68 / 4.6 | 0.64 / 4.1 |
| 亜空切断 | 44 | 近接 | 0.42 / 5.0 | 0.42 / 4.5 |

**CD は反動そのもの。** `stanceOf()` は「撃てる技が1本も無い＝反動」と定義しとる
（`battle.tpl.html:1456-1467`）。長い CD の技を積む＝反動の時間を買うということ。

## 4. 色 —— 4段パレット

`PALETTES`（`fx_core.js:825-834`）は8種。**全部が同じ法則で作られとる**：

```
[0] 白か、白に近い色   ← 芯。ここが光っとるから「エネルギー」に見える
[1] 明るい固有色       ← その技の色だと分かる段
[2] 濃い固有色         ← 主張する段
[3] ほぼ黒に近い暗色   ← 輪郭・影。これが無いと背景に溶ける
```

| キー | 色 |
|---|---|
| 炎 | `#ffffff` `#ffd44a` `#ff7a18` `#c8260c` |
| 水 | `#ffffff` `#b6ecff` `#3fa9f5` `#0b4c9c` |
| 雷 | `#ffffff` `#fff7a0` `#ffd21e` `#8a5a00` |
| 毒 | `#f2d8ff` `#d08cff` `#8e33d6` `#3d0a63` |
| 氷 | `#ffffff` `#ddf6ff` `#8fd8f7` `#2f7fae` |
| 闇 | `#e0d0ff` `#9b7ad6` `#5227a0` `#160a30` |
| 草 | `#f0ffd8` `#b8e986` `#5aa832` `#1f5a18` |
| 鋼 | `#ffffff` `#e6eef6` `#9aa9bb` `#4a5568` |

### 新しい色を作るときの規則

1. **[0] は必ず白か白寄り。** 闇でさえ `#e0d0ff` から始まる。
   ここを固有色にすると「光っとらん絵」になる。加算合成が無い（フレームを焼いて重ねとる）けん、
   **明るさは色そのもので出すしかない**。
2. [1]→[2]→[3] は明度を下げながら彩度を上げ、最後に一気に暗くする。
3. [3] は背景（暗い戦闘画面）より暗く。輪郭が立つ。

### 18タイプ → パレットの当て方（仮）

| タイプ | パレット | | タイプ | パレット |
|---|---|---|---|---|
| ノーマル | 鋼 | | むし | 草 |
| ほのお | 炎 | | いわ | 鋼 |
| みず | 水 | | ゴースト | 闇 |
| でんき | 雷 | | ドラゴン | 闇 |
| くさ | 草 | | あく | 闇 |
| こおり | 氷 | | はがね | 鋼 |

⚠ **仮。** じめん（茶）とひこう（無色）に合う段が無い。技を10本ほど作って

## 5. 画面演出 —— 威力に見合う量だけ

`SCREEN_DEFAULTS`（`fx_core.js:239-246`）の6種。

| キー | 日本語 | パラメータ | 範囲 |
|---|---|---|---|
| `flash` | 閃光 | color, strength, dur, at | strength 0〜1 / dur 0.05〜2 |
| `blink` | 背景点滅 | color, strength, **times**, dur, at | times 1〜16 |
| `tint` | 背景に色 | color, strength, dur, at | |
| `darken` | 暗転 | strength, dur, at | |
| `shake` | 画面揺れ | **power**, dur, at | power 1〜26 |
| `lines` | 走査線 | color, strength, dur, at, **dir** | dir: h（横）/ v（縦） |

### 実測した梯子

内蔵6技を数えると、**画面演出の個数が威力にきれいに比例しとる**：

| 技 | 威力 | screen の数 | 中身 | shake |
|---|---|---|---|---|
| 水弾 | 22 | 2 | tint, shake | 4 |
| 灼熱弾 | 26 | 2 | tint, shake | 5 |
| 三連爪 | 30 | 2 | lines, shake | 6 |
| 落雷 | 34 | 3 | **darken**, blink, shake | 11 |
| 白熱光線 | 40 | 4 | **darken**, lines, **flash**, shake | 9 |
| 亜空切断 | 44 | 5 | **darken**, lines, **flash**, shake, tint | 10 |

ここから規則を出す：

```
screen の個数 = 2（〜威力33） / 3（34〜45） / 4（46〜61） / 5（62〜）
shake.power  = round(power × 0.21)、範囲 3〜26
darken と flash は 威力34以上の技だけに許す ← 大技の特権
```

**`darken` は「これから何か来る」の合図**。小技に付けると意味が薄れて、
本当の大技が来たときに驚かんくなる。**安売りするな。**

### 組み合わせの型

| 型 | 中身 | 向く技 |
|---|---|---|
| 軽い（威力〜33） | `tint`(0.26) + `shake`(4〜7) | 連発技・牽制 |
| 斬撃型 | `lines`(dir:v, 0.45) + `shake` | 近接。縦線が「斬った」を伝える |
| 雷型 | `darken`(cast) + `blink`(times:5) + `shake`(11) | 遠隔。点滅が落雷の明滅 |
| 光線型 | `darken`(cast, 0.60) + `lines`(v, cast) + `flash`(impact, 0.90) + `shake` | **暗転で溜め→直撃で白飛び**の落差 |
| 特大 | 光線型 + `tint`(impact) | 全部載せ。ここまでやるのは威力62以上だけ |

⚠ `screen` には `off` が無い。**同じ `at` に置いたものは全部同時に出る。**
時間差を付けたいなら `parts` を使う（節7）。

## 6. 素材（parts）—— 時間差はここで作る

`fx.parts[]`。各素材は**それ自体が完全な generator の spec**で、加えて配置情報を持つ
（`fx_core.js:700-712`、`movelab.js:300-450`）。

```jsonc
{
  "generator": "shatter", "...": "generator ごとのパラメータ一式",
  "at":     "impact",   // cast 構え / fire 発射 / impact 着弾
  "off":    0.10,       // その瞬間から何秒あと（timeScale で伸び縮みする）
  "anchor": "to",       // from 撃った人 / to 当たった場所 / center 画面の中央
  "dx": 0, "dy": -20    // 基準からのずらし（px）
}
```

### 良い演出は「同時」やのうて「時間差」

外の完成された演出データを見ると、画面効果が**ずらして**置かれとる：

```
0.00 暗転（0.8秒）        ← 舞台を作る
0.10 粒子が出はじめる     ← 予兆
0.15 閃光（0.05秒）       ← 一番強い一撃。暗転の途中で刺す
0.35 揺れ（0.4秒）        ← 音が届いたぶんの遅れ
```

**閃光が暗転の「途中」に刺さっとるのが肝。** 暗転が終わってから光らせると、
ただの明滅になって落差が出ん。`四皇モン` では `screen` に `off` が無いけん、この形を作るには：

- 暗転 → `screen.darken` `at:'cast'`（＝発射の瞬間、`dur` 長め 0.6〜0.8）
- 予兆 → `parts` に小さい素材を `at:'fire'` `off:0.05`
- 閃光 → `screen.flash` `at:'impact'`
- 揺れ → `screen.shake` `at:'impact'`（`dur` を flash より長く）

### 型：素材の使い分け

| やりたいこと | 置き方 |
|---|---|
| 溜めの予兆（構えの最中に光る） | `at:'cast'` `anchor:'from'` `off:0` の小さい `aura` |
| 発射の反動（撃った側に火花） | `at:'fire'` `anchor:'from'` の小さい `projectile` か `slash` |
| 着弾の追い打ち | `at:'impact'` `anchor:'to'` `off:0.08〜0.15` の `shatter` |
| 二段爆発 | `at:'impact'` の素材を `off:0` と `off:0.18` で2つ |
| 頭上／足元 | `dy:-40`（上）／ `dy:+30`（下） |
| 画面全体の異変 | `anchor:'center'` の大きい `shatter` |

**亜空切断が実際にやっとるのがこれ**：本体 slash（2連）＋ `at:'impact'` の shatter。
それだけで「空間を裂いた」に見える。素材は多けりゃええもんやない。**2〜4個**。

⚠ **旧形式 `fx.shatter` は使うな。** `parts[]` に統一されとる
（`fx_core.js:772` に互換処理が残っとるだけ）。技ラボが開いた時点で自動変換される（`movelab.js:323-328`）。

## 7. 本人の動き（motions）

`fx.motions[]`。撃った四皇モン自身にさせるアニメ（`movelab.js:453-512`）。

```jsonc
{ "anim":"charge", "at":"cast", "off":0, "dur":0.75 }
```

使える anim（`movelab.js:50-54`）：

| anim | 日本語 | 使いどころ |
|---|---|---|
| `attack` | 突き出す | 発射の基本 |
| `charge` | 力を溜める | 構え。遠隔技の既定 |
| `jump` | 跳ぶ | 跳び蹴り・落下技 |
| `fly` | 空へ舞う | 飛行技 |
| `dodge` | 横へ跳ぶ | 回避を兼ねた技 |
| `zigzag` | 往復横跳び | 撹乱 |
| `hurt` | のけぞる | **反動ダメージの技** |
| `knockback` | ふっとぶ | 自爆・大反動 |
| `appear` | 降りてくる | 登場 |
| `idle` | 動かん | 動かんことで見せる技 |
| `hold` | 構える | ⚠ 戦闘の「間」からは外した。技演出専用に回した |
| `recoil` | 白く明滅 | ⚠ 同上。**戦闘の反動表現と被るけん慎重に** |

**空なら「発射の瞬間に分類ごとの既定動作」**（`battle.tpl.html:1605-1612`、`move_range.js:81-88`）：

- 近接 → `attack`（既定の長さ。大きく踏み込む）
- 遠距離 → `attack` 0.42秒（短く。前へ出すだけ）
- 遠隔 → `charge` 0.42秒（その場で溜める）

**遠隔技で腕を前に振らせるな。** 実体が飛ばんのに「飛ばした」絵になって分類と食い違う。

### 型

| やりたいこと | motions |
|---|---|
| じっくり溜めて撃つ | `charge`@cast dur=1.2 → `attack`@fire dur=0.25 |
| 撃った反動でのけぞる | `attack`@fire → `hurt`@fire off=0.15 dur=0.3 |
| 突進して斬る | `jump`@cast dur=0.4 → `attack`@fire dur=0.2 |
| 自爆技 | `charge`@cast → `knockback`@impact dur=0.8 |

`dur` でアニメを伸び縮みさせる。0.20秒＝素早い突き、1.50秒＝じっくり溜めた動き。

## 8. 音

`audio[]`（**`fx` の外側**。library.json のトップレベル）。

```jsonc
{ "id":"exp_short", "at":"fire", "off":0, "vol":0.7, "rate":1.1 }
```

- `id` … `docs/SFX_MAP.md` の一覧から。カテゴリは 発射・弾／光線／大砲・重火力／爆発・着弾／
  斬撃／金属・相殺／打撃・近接／被弾／断末魔／魔法・電撃・空間／UI
- `at` … cast / fire / impact
- `off` … その瞬間から何秒あと
- `vol` … 0〜1
- `rate` … 再生速度。**下げると重く、上げると軽くなる**。0.7〜1.3 が実用域

### 層の作り方（亜空切断の実例）

```
cast   +0.00  warp        vol 0.8  rate 0.8   ← 空間の歪み。構えの予告
fire   +0.00  slash2      vol 1.0  rate 0.85  ← 主役の音
fire   +0.06  laser_sharp vol 0.6  rate 0.7   ← 6/100秒ずらして厚みを足す
impact +0.00  clash1      vol 0.9  rate 1.3   ← 当たった瞬間の高い音
impact +0.10  exp_crunch  vol 0.7  rate 0.9   ← 遅れて低い余韻
```

**規則**：

1. **主役の音は1つ。** `vol 1.0` はそれだけ。他は 0.6〜0.9 で敷く。
2. **重ねるときは 0.04〜0.10 秒ずらす。** 完全同時に鳴らすと1つの潰れた音になる。
3. **高い音が先、低い音が後。** 現実の音がそう届く。`clash1`(1.3) → `exp_crunch`(0.9)。
4. **`rate` で技の重さを作る。** 同じ `exp_short` でも 1.1 なら軽い炸裂、0.75 なら大爆発。
   **音源を増やすより rate をいじる方が効く。**
5. 小技は 2音（fire + impact）、大技は 4〜5音。

## 10. 禁じ手

`CLAUDE.md` の掟から、演出に効くものだけ抜いた。**破ると戦闘が壊れる。**

1. **`setTimeout` を使うな。** 遅延は必ず `off` と `DelayFX`（固定タイムステップ）。
   使うと戦闘の決定論が壊れる（`fx_core.js:713-714`）。
2. **`Math.random()` を使うな。** 揺らぎは `seed` から作る（`RNG` / `hash3`）。
   同じ技は誰が撃っても同じ絵にならんといかん。
3. **画像を増やすな（掟4）。** 新しい絵は描かん。既存の generator と anim の組み合わせだけで出す。
4. **素材を作る経路を増やすな。** 技ラボ・制作ツール・戦闘は `spawnSubFX()` だけを使う。
   別々に書いた結果「亜空切断の割れが戦闘にだけ出る」が実際に起きた（`fx_core.js:715-716`）。
5. **`screen` を素材ごとに持たせるな。** 本体側だけが持つ。重なりすぎる（`movelab.js:316`）。
6. **にーくらの自作技に触るな。** `data/moves/library.json` の既存キーは上書き禁止。
7. **数字をコードに直書きするな（掟9）。** 技の値は `library.json` か `MOVES` に集める。

## 11. 完成例 —— 「終焔柱」を一から

**狙い**：ほのお・特大・遠隔。落雷を炎に置き換え、足元から噴き上がる火柱。

**手順1〜2（戦闘値）**
```
type ほのお / generator lightning → range remote
power 72
cast     = clamp( (0.05+0.0115×72) × 1.45, 0.15, 1.30 ) = clamp(1.273) → 1.27
cooldown = clamp( (0.60+0.0750×72) × 1.30, 1.30, 7.00 ) = clamp(7.80) → 7.0（上限）
tags = 高威力 / とどめ向き / 瀕死時危険 / 回避されやすい（remote かつ cast≥0.8）
```

**手順3（主役）** —— `fromSky:false` が「柱」の正体
```jsonc
{ "generator":"lightning", "width":18, "jag":0.35, "branches":9, "segments":6,
  "duration":0.90, "fromSky":false,
  "impact":{ "size":150, "frames":16, "shards":34 } }
```

`branches` を 9 に上げて、噴き上がる枝を増やす。

**手順4（色）** —— 炎パレット `#ffffff` `#ffd44a` `#ff7a18` `#c8260c`

**手順5（画面）** —— 威力72＝特大＝5つ全部、shake は round(72×0.21)=15
```jsonc
"screen": {
  "darken":{"strength":0.66,"dur":0.70,"at":"cast"},
  "lines" :{"color":"#ffb060","strength":0.45,"dur":0.55,"at":"cast","dir":"v"},
  "flash" :{"color":"#fff0d0","strength":0.95,"dur":0.16,"at":"impact"},
  "shake" :{"power":15,"dur":0.50,"at":"impact"},
  "tint"  :{"color":"#ff5a00","strength":0.38,"dur":0.60,"at":"impact"}
}
```
縦の走査線が「下から上へ」を伝える。

**手順6（素材3つ）**
```jsonc
"parts":[

    "at":"cast","off":0,"anchor":"from","dx":0,"dy":20 },        // 足元に熱が集まる
  { "generator":"shatter","size":220,"cracks":18,"jag":0.7,"drift":110,"dust":70,"duration":1.0,
    "at":"impact","off":0,"anchor":"to","dx":0,"dy":10 },        // 地面が割れる

    "travel":{"speed":180,"arc":-60,"spin":6},
```

**手順7（動き2つ）**

## 12. 今のシステムの穴（直す価値がある順）

作っとって見つかった、**演出の表現力を縛っとる箇所**。直すかどうかはにーくらの判断。

1. **`screen` に `off` が無い。** 同じ `at` の効果が全部同時に出る。
   節6の「暗転の途中に閃光を刺す」形が作れん。
   → `SCREEN.trigger()`（`fx_core.js:251-256`）に `off` を足せば済む。`parts` と同じ仕組み。
2. **`screen` の `at` に `fire` が無い。** parts/motions/audio は3段階あるのに screen だけ2段階。
   そのうえ `screen.at:'cast'` の実際の発火は fire。**名前と実装が食い違っとる。**
   → `at:'cast'`（真の構え）を足して、今の 'cast' は 'fire' に改名するのが筋。互換のため両方受ける。
3. **加算合成が無い。** フレームを焼いて重ねる方式やけん、明るさはパレットの [0] でしか出せん。
   → 光る技の幅は今のところ色作りで稼ぐしかない。大きな改修になるけん優先度は低い。
4. **じめん／ひこう に合うパレットが無い。** 節4参照。技が増えたら効いてくる。
